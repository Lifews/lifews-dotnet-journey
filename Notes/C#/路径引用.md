### 斜杠的作用

| 场景                     | 主要使用的斜杠  | 作用         |
| :----------------------- | :-------------- | :----------- |
| **Windows 文件路径**     | `\`             | 分隔文件夹   |
| **Linux/macOS 文件路径** | `/`             | 分隔文件夹   |
| **URL 和 Web**           | `/`             | 分隔路径部分 |
| **字符串转义**           | `\`             | 转义特殊字符 |
| **数学运算**             | `/`             | 除法运算符   |
| **注释**                 | `//` 或 `/* */` | 注释代码     |



#### 文件系统中的斜杠

```C#
// 分隔目录层级
/root/home/user/documents  // 绝对路径
./project/src/main.cs      // 相对路径
../parent-folder/file.txt  // 上级目录
```



#### 编程中的斜杠

```C#
// C# 中的各种用途
string path1 = @"C:\Windows\System32";  // 逐字字符串
string path2 = "C:/Program Files/App";  // 正斜杠路径
string url = "https://api.example.com/v1/users";
int division = 15 / 3;                   // 数学除法
// 注释行
```



#### Web 开发中的斜杠

```html
<!-- HTML 和 URL -->
<img src="/images/photo.jpg">
<a href="/about/contact">联系</a>
```



### 正斜杠(`/`)和反斜杠(`\`)

在路径处理中有重要区别：

| 特性                 | 正斜杠 `/`                   | 反斜杠 `\`                 |
| :------------------- | :--------------------------- | :------------------------- |
| **系统支持**         | Windows、Linux、macOS 都支持 | 主要是 Windows 系统        |
| **跨平台兼容性**     | ✅ 优秀                       | ❌ 差（Linux/macOS 不识别） |
| **在字符串中的使用** | 直接使用                     | 需要转义为 `\\`            |
| **推荐程度**         | ⭐⭐⭐⭐⭐ 推荐                   | ⭐⭐ 不推荐                  |
