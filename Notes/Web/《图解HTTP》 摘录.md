# IP地址

**IP地址** 是 **互联网协议地址** 的简称。它是一串用于标识和定位网络中设备的**唯一数字编号**，是设备接入互联网的基础。

#### **1. 格式与版本**

目前我们主要使用两种格式：

- **IPv4**：最普遍的版本，格式为四组用点分隔的数字，每组范围0-255。
  - **例如**：`192.168.1.1`、`8.8.8.8`（谷歌的公共DNS服务器）。
  - 理论上约有43亿个地址，但早已不够用。
- **IPv6**：新一代协议，用于解决IPv4地址耗尽问题。格式为八组用冒号分隔的十六进制数。
  - **例如**：`2001:0db8:85a3:0000:0000:8a2e:0370:7334`
  - 地址数量近乎无限。

#### **2. 结构：网络号 + 主机号**

一个IP地址包含两部分信息（通过**子网掩码**来划分）：

- **网络号**：标识设备所属的**特定网络**（比如你家、你公司、一个数据中心）。相当于城市的区号或邮政编码。
- **主机号**：标识该网络内的**特定设备**。相当于该区域内的具体门牌号。
- **例子**：在IP `192.168.1.100`（子网掩码 `255.255.255.0`）中：
  - `192.168.1` 是网络号。
  - `.100` 是主机号。

#### **3. 地址类型**

- **公网IP地址**：在互联网上全球唯一的地址，由运营商分配。就像你家的全球邮寄地址。访问网站时，你的公网IP会被网站记录。
- **私网IP地址**：在局域网（如家庭、办公室Wi-Fi）内部使用的地址，不能在互联网上直接路由。常见于 `192.168.x.x`、`10.x.x.x` 等范围。多个家庭的私网IP可以对应同一个运营商的公网IP（通过NAT技术），这大大节省了公网IP资源。
- **特殊地址**：
  - `127.0.0.1`：称为 **本地回环地址**，总是指向本机。用于测试网络软件。
  - `0.0.0.0`：通常表示“本网络”或“任意地址”。

#### **4. 如何获取IP地址？**

- **手动配置**：管理员手动为设备设置固定的IP（静态IP）。
- **自动分配**：更常见的方式，通过 **DHCP协议** 从路由器或服务器自动获取一个可用的IP地址（动态IP）。你连接Wi-Fi时就是这样。





# URI

**URI** 是 **统一资源标识符**。它的核心作用是 **唯一地标识一个资源**。

这个“资源”可以是网页、图片、文档、服务，甚至是抽象的概念（如“今天北京的天气”）。

HTTP协议使用URI定位互联网上的资源。正是因为URI的特定功能，在互联网上任意位置的资源都能访问到。

| 特性                 | **URI**                       | **URL**                      |
| :------------------- | :---------------------------- | :--------------------------- |
| **全称**             | 统一资源 **标识符**           | 统一资源 **定位符**          |
| **核心目的**         | **标识** 一个资源             | **定位** 一个资源            |
| **范围**             | **广义**概念，包含 URL 和 URN | **狭义**概念，是 URI 的一种  |
| **是否包含访问方式** | 不一定（URN就不包含）         | **总是**包含（协议、路径等） |
| **类比**             | **身份证号**（用于标识）      | **家庭住址**（用于找到）     |





# URL

URL（Uniform Resource Locator，统一资源定位符）就是我们在浏览器地址栏中看到的那串字符，用来唯一标识互联网上的一个资源（比如一个网页、一张图片、一个 API 接口）。

```
https://example.com:443/products?category=electronics&page=2#reviews
```

- **协议**（`https://`）：告诉浏览器如何与服务器通信，如 HTTP、HTTPS、FTP 等。
- **域名/IP**（`example.com`）：服务器的地址。
- **端口**（`:443`）：服务器上具体服务的入口，默认端口可省略（HTTP 默认 80，HTTPS 默认 443）。
- **路径**（`/products`）：定位到服务器上的具体资源或接口。
- **查询字符串**（`?category=electronics&page=2`）：以 `?` 开头，用 `key=value` 形式传递额外参数，多个参数用 `&` 连接。
- **片段标识符**（`#reviews`）：用于定位页面内的某个位置，不会发送给服务器。

### 什么是查询字符串（Query String）？

查询字符串是 URL 中 `?` 之后的部分，用于向服务器传递**非层级**的附加数据。它由键值对组成，格式为 `key1=value1&key2=value2`

```url
GET /api/users?role=admin&sort=age&page=1
```

这里通过查询字符串告诉服务器：我要获取角色为 admin 的用户，按年龄排序，并且只返回第一页数据。

**常见用途**：

- **过滤**：`?category=books`
- **排序**：`?sort=price_desc`
- **分页**：`?page=2&limit=20`
- **搜索关键词**：`?q=asp.net`
- **标识资源**（虽然 REST 中资源 ID 通常放在路径里，但有时也会用查询字符串表示复合标识）



### 其他传参方式？

参数本质上就是**键值对数据**，它们可以出现在不同的位置：

| 位置           | 常见用途                           | 示例                         |
| :------------- | :--------------------------------- | :--------------------------- |
| **路径参数**   | 资源的唯一标识（REST 风格）        | `/users/{id}` → `/users/123` |
| **查询字符串** | 过滤、排序、分页等可选条件         | `/users?role=admin&page=2`   |
| **请求头**     | 元数据，如认证令牌、内容类型       | `Authorization: Bearer xxx`  |
| **请求体**     | 提交大量或敏感数据（如 POST、PUT） | JSON 格式的表单数据          |
