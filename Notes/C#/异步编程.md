



## 异步编程



### 如何创建异步任务？



#### **基本模式**

```C#
// 返回 Task<T> 的异步方法
public async Task<int> CalculateResultAsync(int input)
{
    // 模拟异步操作
    await Task.Delay(1000); // 异步等待1秒
    
    return input * 2; // 返回结果会自动包装在Task中
}

// 返回 Task 的异步方法（无返回值）
public async Task ProcessDataAsync(string data)
{
    // 模拟异步操作
    await Task.Delay(500);
    
    Console.WriteLine($"Processing: {data}");
    // 无需return语句
}
```

#### **调用异步方法**

```c#
public async Task UseAsyncMethods()
{
    // 调用并等待结果
    int result = await CalculateResultAsync(5);
    Console.WriteLine($"Result: {result}");
    
    // 启动异步操作但不立即等待
    Task processingTask = ProcessDataAsync("test");
    
    // 执行其他工作...
    
    // 然后等待任务完成
    await processingTask;
}
```

#### `Task.Run` 执行CPU密集型工作

```c#
public Task<int> CalculateComplexResultAsync(int input)
{
    return Task.Run(() =>
    {
        // CPU密集型计算
        int result = 0;
        for (int i = 0; i < 1000000; i++)
        {
            result += input * i;
        }
        return result;
    });
}
```

#### `Task.Delay` 创建延迟任务

```c#
public async Task PollUntilCompleteAsync(Func<bool> isComplete, int pollIntervalMs, int timeoutMs)
{
    var timeoutTask = Task.Delay(timeoutMs);
    while (!isComplete())
    {
        // 等待一段时间或超时
        var delayTask = Task.Delay(pollIntervalMs);
        var completedTask = await Task.WhenAny(delayTask, timeoutTask);
        
        if (completedTask == timeoutTask)
        {
            throw new TimeoutException("Operation timed out");
        }
    }
}
```

#### `Task.WhenAll` 和 `Task.WhenAny` 组合任务

```c#
public async Task<string[]> DownloadMultipleUrlsAsync(IEnumerable<string> urls)
{
    var client = new HttpClient();
    var downloadTasks = urls.Select(url => client.GetStringAsync(url)).ToArray();
    
    // 等待所有下载完成
    return await Task.WhenAll(downloadTasks);
}

public async Task<string> GetFirstResponseAsync(params string[] urls)
{
    var client = new HttpClient();
    var downloadTasks = urls.Select(url => client.GetStringAsync(url)).ToArray();
    
    // 等待任意一个下载完成
    var completedTask = await Task.WhenAny(downloadTasks);
    
    return await completedTask;
}
```



> [!TIP]
>
> - **命名约定**：异步方法应以"Async"为后缀
> - **异常处理**：确保正确处理异步方法中的异常
> - **避免async void**：除了事件处理程序，始终返回Task或Task<T>
> - **配置等待**：在库代码中使用`ConfigureAwait(false)`避免不必要的上下文切换
> - **取消支持**：支持`CancellationToken`以使异步操作可取消,每个异步方法都应该有`CancellationToken`









### 如何同时开始多个异步任务？

####  `Task.WhenAll`

```C#
using System;
using System.Net.Http;
using System.Threading.Tasks;

class Program
{
    static async Task Main(string[] args)
    {
        // 创建多个异步任务
        var task1 = DownloadWebsiteAsync("https://www.example.com");
        var task2 = DownloadWebsiteAsync("https://www.example.org");
        var task3 = DownloadWebsiteAsync("https://www.example.net");

        // 同时开始所有任务并等待它们全部完成
        string[] results = await Task.WhenAll(task1, task2, task3);

        // 处理结果
        foreach (var result in results)
        {
            Console.WriteLine($"Downloaded {result.Length} characters");
        }
    }

    static async Task<string> DownloadWebsiteAsync(string url)
    {
        using var httpClient = new HttpClient();
        return await httpClient.GetStringAsync(url);
    }
}
```

#### `Task.Run` 和 `Task.WhenAll` 结合

```C#
using System;
using System.Threading.Tasks;

class Program
{
    static async Task Main(string[] args)
    {
        // 创建多个任务（将同步方法包装为异步任务）
        var task1 = Task.Run(() => ProcessData("Data1"));
        var task2 = Task.Run(() => ProcessData("Data2"));
        var task3 = Task.Run(() => ProcessData("Data3"));

        // 等待所有任务完成
        await Task.WhenAll(task1, task2, task3);
        
        Console.WriteLine("All tasks completed!");
    }

    static void ProcessData(string data)
    {
        // 模拟耗时操作
        System.Threading.Thread.Sleep(1000);
        Console.WriteLine($"Processed: {data}");
    }
}
```

####  Parallel 类（对于 CPU 密集型操作）

对于 CPU 密集型操作，可以使用 `Parallel` 类：

```C#
using System;
using System.Threading.Tasks;

class Program
{
    static void Main(string[] args)
    {
        var data = new string[] { "Data1", "Data2", "Data3", "Data4" };

        // 并行处理数据
        Parallel.ForEach(data, item =>
        {
            ProcessData(item);
        });
        
        Console.WriteLine("All processing completed!");
    }

    static void ProcessData(string data)
    {
        // 模拟耗时操作
        System.Threading.Thread.Sleep(1000);
        Console.WriteLine($"Processed: {data}");
    }
}
```

#### 异步流 (C# 8.0+)

对于需要处理异步数据流的情况，可以使用异步流：

```C#
using System;
using System.Collections.Generic;
using System.Threading.Tasks;

class Program
{
    static async Task Main(string[] args)
    {
        await foreach (var result in ProcessMultipleDataAsync())
        {
            Console.WriteLine($"Received: {result}");
        }
    }

    static async IAsyncEnumerable<string> ProcessMultipleDataAsync()
    {
        var tasks = new List<Task<string>>
        {
            ProcessDataAsync("Data1"),
            ProcessDataAsync("Data2"),
            ProcessDataAsync("Data3")
        };

        // 当每个任务完成时返回结果
        while (tasks.Count > 0)
        {
            var completedTask = await Task.WhenAny(tasks);
            tasks.Remove(completedTask);
            yield return await completedTask;
        }
    }

    static async Task<string> ProcessDataAsync(string data)
    {
        await Task.Delay(1000); // 模拟异步操作
        return $"Processed {data}";
    }
}
```

#### 使用 SemaphoreSlim 控制并发数

如果需要限制同时运行的异步任务数量，可以使用信号量：

```C#
using System;
using System.Collections.Generic;
using System.Threading.Tasks;

class Program
{
    static async Task Main(string[] args)
    {
        var urls = new string[]
        {
            "https://www.example.com",
            "https://www.example.org",
            "https://www.example.net",
            "https://www.microsoft.com",
            "https://www.github.com"
        };

        // 限制最多同时3个下载任务
        var results = await DownloadAllWithLimitAsync(urls, 3);
        
        foreach (var result in results)
        {
            Console.WriteLine($"Downloaded {result.Length} characters");
        }
    }

    static async Task<string[]> DownloadAllWithLimitAsync(string[] urls, int maxConcurrency)
    {
        var allTasks = new List<Task<string>>();
        var semaphore = new SemaphoreSlim(maxConcurrency);

        foreach (var url in urls)
        {
            await semaphore.WaitAsync();
            allTasks.Add(Task.Run(async () =>
            {
                try
                {
                    return await DownloadWebsiteAsync(url);
                }
                finally
                {
                    semaphore.Release();
                }
            }));
        }

        return await Task.WhenAll(allTasks);
    }

    static async Task<string> DownloadWebsiteAsync(string url)
    {
        using var httpClient = new HttpClient();
        return await httpClient.GetStringAsync(url);
    }
}
```



### 任务如何取消？

#### 简单的取消示例

```C#
using System;
using System.Threading;
using System.Threading.Tasks;

class Program
{
    static async Task Main(string[] args)
    {
        // 创建CancellationTokenSource
        var cts = new CancellationTokenSource();
        
        // 启动异步任务，传递取消令牌
        var task = DoWorkAsync(cts.Token);
        
        // 等待一段时间后取消任务
        await Task.Delay(2000);
        cts.Cancel();
        
        try
        {
            await task;
            Console.WriteLine("任务完成。");
        }
        catch (OperationCanceledException)
        {
            Console.WriteLine("任务被取消。");
        }
        finally
        {
            cts.Dispose();
        }
    }
    
    static async Task DoWorkAsync(CancellationToken cancellationToken)
    {
        for (int i = 0; i < 10; i++)
        {
            // 检查取消请求
            cancellationToken.ThrowIfCancellationRequested();
            
            Console.WriteLine($"工作进度：{i * 10}%");
            await Task.Delay(500, cancellationToken);
        }
    }
}
```

```C#
}
```

#### 多个任务使用同一个取消令牌

```C#
using System;
using System.Threading;
using System.Threading.Tasks;

class Program
{
    static async Task Main(string[] args)
    {
        using var cts = new CancellationTokenSource();
        
        // 启动多个任务，使用同一个取消令牌
        var task1 = DoWorkAsync("任务1", cts.Token);
        var task2 = DoWorkAsync("任务2", cts.Token);
        var task3 = DoWorkAsync("任务3", cts.Token);
        
        // 3秒后取消所有任务
        await Task.Delay(3000);
        cts.Cancel();
        
        try
        {
            await Task.WhenAll(task1, task2, task3);
        }
        catch (OperationCanceledException)
        {
            Console.WriteLine("所有任务已被取消。");
        }
    }
    
    static async Task DoWorkAsync(string taskName, CancellationToken cancellationToken)
    {
        for (int i = 0; i < 10; i++)
        {
            cancellationToken.ThrowIfCancellationRequested();
            Console.WriteLine($"{taskName} 进度：{i * 10}%");
            await Task.Delay(1000, cancellationToken);
        }
    }
}
```

#### 链接取消令牌

```C#
using System;
using System.Threading;
using System.Threading.Tasks;

class Program
{
    static async Task Main(string[] args)
    {
        // 创建两个取消令牌源
        using var cts1 = new CancellationTokenSource();
        using var cts2 = new CancellationTokenSource();
        
        // 创建一个链接令牌，当任一源取消时都会触发
        using var linkedCts = CancellationTokenSource.CreateLinkedTokenSource(
            cts1.Token, cts2.Token);
        
        var task = DoWorkAsync(linkedCts.Token);
        
        // 2秒后取消第一个令牌源
        await Task.Delay(2000);
        cts1.Cancel();
        
        try
        {
            await task;
        }
        catch (OperationCanceledException)
        {
            Console.WriteLine("任务已被取消。");
        }
    }
    
    static async Task DoWorkAsync(CancellationToken cancellationToken)
    {
        for (int i = 0; i < 10; i++)
        {
            cancellationToken.ThrowIfCancellationRequested();
            Console.WriteLine($"工作进度：{i * 10}%");
            await Task.Delay(500, cancellationToken);
        }
    }
}
```

#### 自定义取消检查

```C#
using System;
using System.Threading;
using System.Threading.Tasks;

class Program
{
    static async Task Main(string[] args)
    {
        using var cts = new CancellationTokenSource();
        
        // 3秒后取消
        cts.CancelAfter(3000);
        
        try
        {
            await DoWorkWithCleanupAsync(cts.Token);
        }
        catch (OperationCanceledException)
        {
            Console.WriteLine("任务已被取消。");
        }
    }
    
    static async Task DoWorkWithCleanupAsync(CancellationToken cancellationToken)
    {
        try
        {
            for (int i = 0; i < 10; i++)
            {
                // 检查取消请求但不抛出异常
                if (cancellationToken.IsCancellationRequested)
                {
                    Console.WriteLine("检测到取消请求，正在清理...");
                    // 执行清理操作
                    await CleanupAsync();
                    // 手动抛出取消异常
                    throw new OperationCanceledException(cancellationToken);
                }
                
                Console.WriteLine($"工作进度：{i * 10}%");
                await Task.Delay(500, cancellationToken);
            }
        }
        finally
        {
            // 确保资源清理
            Console.WriteLine("执行最终清理。");
        }
    }
    
    static async Task CleanupAsync()
    {
        Console.WriteLine("执行清理操作...");
        await Task.Delay(500); // 模拟异步清理
    }
}
```

#### 在异步流中使用取消

```C#
using System;
using System.Collections.Generic;
using System.Threading;
using System.Threading.Tasks;

class Program
{
    static async Task Main(string[] args)
    {
        using var cts = new CancellationTokenSource();
        
        // 3秒后取消
        cts.CancelAfter(3000);
        
        try
        {
            await foreach (var item in GenerateDataAsync(cts.Token))
            {
                Console.WriteLine($"收到数据: {item}");
            }
        }
        catch (OperationCanceledException)
        {
            Console.WriteLine("数据生成被取消。");
        }
    }
    
    static async IAsyncEnumerable<int> GenerateDataAsync([System.Runtime.CompilerServices.EnumeratorCancellation] CancellationToken cancellationToken = default)
    {
        for (int i = 0; i < 10; i++)
        {
            cancellationToken.ThrowIfCancellationRequested();
            await Task.Delay(500, cancellationToken);
            yield return i;
        }
    }
}
```
