# 数据库

--20250729

数据库是后端开发的基石，而.NET生态中的ORM工具能大幅提升开发效率。



## 软件与数据存取流程

> [!NOTE]
>
> 用户操作 → .NET程序 → ADO.NET/EF Core → SQL Server → 返回数据 → 显示结果

Q：为什么需要一个SQL Server？不能直接访问数据吗？

A：

- **解耦**：界面、逻辑、数据存储分离，便于维护。（任何一个程序都可以访问这个数据库，不绑定）
- **安全**：通过参数化查询防止SQL注入。（SQL Server会提供验证功能，需要通过验证才能访问数据库）
- **性能优化**：数据库专门优化了数据操作，比直接操作文件快得多。



## 数据库基础概念

1. **关系型数据库（如SQL Server、MySQL）**

   - 数据以“表”形式组织，每张表有固定列（字段）和多行数据（记录）。

   - 通过**SQL语言**操作数据，例如：

     ```sql
     SELECT * FROM Users WHERE Age > 20; -- 查询
     INSERT INTO Users (Name) VALUES ('Alice'); -- 插入
     ```

   - 核心概念：**主键**（唯一标识行）、**外键**（表间关联）、**索引**（加速查询）。

2. **为何需要数据访问技术？**
   程序不能直接操作数据库文件，需通过：

   - **ADO.NET**：.NET内置的底层数据库连接库（需手动写SQL）。
   - **ORM框架**：在ADO.NET上封装，用面向对象方式操作数据库，避免手写SQL。



## 核心概念解析：ORM是什么？

- **ORM（对象关系映射）**
  将数据库表映射为程序中的“类”，表中的一行数据对应一个“对象”。
  - 表 → 类（如 `User` 类）
  - 表的列 → 类的属性（如 `User.Name`）
  - 表的行 → 类的实例（如 `new User(){ Name="Tom" }`）
    作用：用操作对象的方式间接操作数据库，减少SQL编写。



## .NET中的主流ORM框架

### 1. **Entity Framework Core（EF Core）**

- **官方出品**，生态完善，深度集成.NET技术栈46。

- **核心组件**：

  - `DbContext`：数据库连接入口，管理实体状态。
  - 实体类（Entity）：如 `public class User { public int Id {get; set;} }`。
  - **迁移（Migration）**：通过C#代码修改数据库结构（如增减字段）6。

- **代码示例**（查询数据）：

  ```C#
  using var db = new AppDbContext();
  var users = db.Users.Where(u => u.Age > 20).ToList(); // 无需写SQL！
  ```

### 2. **SqlSugar**

- **国产轻量级ORM**，语法简洁，性能出色，对国产数据库（如达梦、人大金仓）支持更好。

- **特点**：

  - 支持 **`DbFirst`**（从数据库生成实体类）和 **`CodeFirst`**（用实体类生成数据库）。
  - 批量操作效率高，适合大数据场景。

- **代码示例**（插入数据）：

  ```C#
  var db = new SqlSugarClient(connectionConfig);
  db.Insertable(new User{ Name="Alice" }).ExecuteCommand();
  ```

### 3. **EF Core vs SqlSugar 对比**

| **特性**       | **EF Core**              | **SqlSugar**             |
| :------------- | :----------------------- | :----------------------- |
| 背景           | 微软官方维护             | 国产开源                 |
| 学习曲线       | 较陡峭（功能多）         | 平缓（API简洁）10        |
| 性能           | 中等（需优化）           | 更高（尤其批量操作）     |
| 国产数据库支持 | 一般                     | **优秀**（达梦、金仓等） |
| 适用场景       | 大型项目、官方技术栈整合 | 快速开发、高性能需求     |



## 学习路径建议

1. **先掌握数据库基础**
   - 理解表、字段、主键、SQL语法（SELECT/INSERT/UPDATE/DELETE）。
   - 工具：安装SQL Server Express或SQLite，动手建表并写简单查询。
2. **尝试ADO.NET（了解即可）**
   - 用 `SqlConnection` 和 `SqlCommand` 执行SQL，明白ORM的底层原理。
3. **深入ORM框架**
   - **EF Core入门**：
     - 创建 `DbContext` 和实体类。
     - 学习迁移命令（`Add-Migration`, `Update-Database`）。
     - 官方教程：[EF Core文档](https://learn.microsoft.com/ef/core/)
   - **SqlSugar入门**：
     - 用`DbFirst`生成实体类，再用LINQ语法操作数据。
     - 参考：[SqlSugar开源地址](https://github.com/donet5/SqlSugar)
4. **进阶内容**
   - 性能优化（如避免EF Core的N+1查询问题）。
   - 事务管理、并发控制。
   - 缓存机制（如Redis集成）。

**数据库基础 → ADO.NET原理 → ORM概念 → EF Core/SqlSugar实战**



## 基础概念：CRUD是什么？

​	**CRUD** 是数据库和软件开发中最基础的操作概念，代表数据的 **增删改查** 四种核心操作。它描述了应用程序与数据库交互的基本方式，是几乎所有系统（如网站、APP）处理数据的底层逻辑。

| 操作  | 英文       | 作用                      |
| :---- | :--------- | :------------------------ |
| **C** | **Create** | 创建新数据                |
| **R** | **Read**   | 读取/查询数据（**检索**） |
| **U** | **Update** | 修改现有数据              |
| **D** | **Delete** | 删除数据                  |
