## Sql多表联结查询

​	SQL 中的 **联结（JOIN）** 是关系型数据库的核心操作之一，用于根据两个或多个表之间的相关列（通常是主键和外键）来组合这些表中的行。它允许你从多个表中提取相关联的数据，形成更完整的结果集。

### 内联结

INNER JOIN

- **含义：** 返回两个表中**连接条件完全匹配**的行。如果左表的某行在右表中没有匹配的行，或者右表的某行在左表中没有匹配的行，那么这些行都不会出现在结果集中。

- **可视化：** 两个圆（表）的交集部分。

- **语法：**

  ```sql
  SELECT 列名
  FROM 表1
  INNER JOIN 表2
  ON 表1.关联列 = 表2.关联列;
  -- 'INNER' 关键字通常可以省略，只用 JOIN 默认就是 INNER JOIN
  ```

### 左外联结

LEFT OUTER JOIN 或 LEFT JOIN

- **含义：** 返回**左表的所有行**，即使在右表中没有匹配的行。对于左表中在右表没有匹配的行，结果集中右表相关的列将显示为 `NULL`。

- **可视化：** 整个左圆（左表），加上与右圆相交的部分。

- **语法：**

  ```sql
  SELECT 列名
  FROM 表1 (左表)
  LEFT [OUTER] JOIN 表2 (右表)
  ON 表1.关联列 = 表2.关联列;
  -- 'OUTER' 关键字通常可以省略。
  ```

### 右外联结

RIGHT OUTER JOIN 或 RIGHT JOIN

- **含义：** 返回**右表的所有行**，即使在左表中没有匹配的行。对于右表中在左表没有匹配的行，结果集中左表相关的列将显示为 `NULL`。

- **可视化：** 整个右圆（右表），加上与左圆相交的部分。

- **语法：**

  ```sql
  SELECT 列名
  FROM 表1 (左表)
  RIGHT [OUTER] JOIN 表2 (右表)
  ON 表1.关联列 = 表2.关联列;
  -- 'OUTER' 关键字通常可以省略。
  ```

- **注意：** 右联结通常可以通过交换表的顺序并使用左联结来实现，因此实际工作中基本只使用左联结。

### 全外联结

FULL OUTER JOIN 或 FULL JOIN

- **含义：** 返回左表和右表中的**所有行**。当某行在另一个表中没有匹配行时，则另一个表相关的列将显示为 `NULL`。如果两个表有匹配的行，则它们会像内联结一样组合。

- **可视化：** 左圆和右圆的并集。

- **语法：**

  ```sql
  SELECT 列名
  FROM 表1
  FULL [OUTER] JOIN 表2
  ON 表1.关联列 = 表2.关联列;
  -- 'OUTER' 关键字通常可以省略。
  ```

### 交叉联结

CROSS JOIN

- **含义：** 返回两个表的**笛卡尔积**。即左表中的每一行与右表中的每一行进行组合。结果集的行数等于左表行数乘以右表行数。**它没有连接条件（ON 子句）。**

- **可视化：** 左表的每一行都与右表的每一行连接一次。

- **语法：**

  ```sql
  SELECT 列名
  FROM 表1
  CROSS JOIN 表2;
  ```



## 导航查询

​	“导航查询”（Navigation Query）是**面向对象编程（OOP）** 和 **对象关系映射（ORM）框架**（如 Entity Framework Core, Hibernate, NHibernate, Django ORM 等）中的一个核心概念。它指的是**通过对象之间的关联属性（导航属性）来访问和查询相关联数据**的方式。
