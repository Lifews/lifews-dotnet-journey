## Json

JSON（JavaScript Object Notation）是一种轻量级的数据交换格式。它采用完全独立于语言的文本格式，但使用了类似于 C 语言家族（包括 C, C++, C#, Java, JavaScript, Python 等）的习惯。这些特性使 JSON 成为理想的数据交换语言，易于人阅读和编写，同时也易于机器解析和生成。



### JSON 的六大基本结构

JSON 建立在两种基本结构之上，并通过它们组合成复杂的数据结构：

1. **对象 (Object)**： 由花括号 `{}` 包裹的**键值对**集合。在各种语言中，它被理解为对象、记录、结构、字典、哈希表或关联数组。
2. **数组 (Array)**： 由方括号 `[]` 包裹的**值**的有序列表。在大多数语言中，它被实现为数组、向量、列表或序列。

JSON 的值可以是以下六种数据类型之一：

|         类型         | 描述                                                         | 示例                                           |
| :------------------: | :----------------------------------------------------------- | :--------------------------------------------- |
| **字符串 (String)**  | 由双引号 `""` 包裹的任意数量的 Unicode 字符。**必须使用双引号**。 | `"hello"`, `"姓名"`, `"\u4e2d"` (转义中文‘中’) |
|  **数字 (Number)**   | 整数或浮点数，**不支持八进制和十六进制**格式。               | `42`, `3.14159`, `-7`, `0.8e4`                 |
| **布尔值 (Boolean)** | 真或假。                                                     | `true`, `false`                                |
|   **空值 (Null)**    | 一个空值。                                                   | `null`                                         |
|  **对象 (Object)**   | 无序的键值对集合。                                           | `{ "name": "张三", "age": 30 }`                |
|   **数组 (Array)**   | 有序的值的列表。                                             | `["apple", "banana", "cherry"]`                |



### 语法规则详解

#### 1. 对象 (Object)

- **语法**： 写在花括号 `{}` 中。

- **内容**： 包含零个或多个**键值对**。

- **键值对**： 写作 `"键": 值`。

  - **键 (Key)**： **必须是字符串**，由双引号 `""` 包裹。
  - **值 (Value)**： 可以是任何有效的 JSON 数据类型（字符串、数字、对象、数组等）。

- **分隔**： 键值对之间使用**逗号 `,`** 分隔。

- **示例**：

  json

  ```
  {
    "name": "Alice",
    "age": 30,
    "isStudent": false,
    "address": {
      "city": "New York",
      "postalCode": "10001"
    },
    "hobbies": ["reading", "hiking"]
  }
  ```



#### 2. 数组 (Array)

- **语法**： 写在方括号 `[]` 中。

- **内容**： 包含零个或多个**值**。

- **值**： 可以是任何有效的 JSON 数据类型。

- **分隔**： 值之间使用**逗号 `,`** 分隔。

- **示例**：

  json

  ```
  ["apple", "banana", "cherry"]
  ```

  json

  ```
  [
    1,
    2,
    [3, 4],
    { "fruit": "mango" }
  ]
  ```



#### 3. 字符串 (String)

- **必须使用双引号** `""` 包裹。单引号 `''` 是**无效的**。

- **转义字符**： 字符串中可以包含以下转义字符：

  | 转义序列 | 含义                                |
  | :------- | :---------------------------------- |
  | `\"`     | 双引号                              |
  | `\\`     | 反斜杠                              |
  | `\/`     | 正斜杠 (可选)                       |
  | `\b`     | 退格符                              |
  | `\f`     | 换页符                              |
  | `\n`     | 换行符                              |
  | `\r`     | 回车符                              |
  | `\t`     | 制表符                              |
  | `\uXXXX` | Unicode 码位 (如 `\u4e2d` 表示‘中’) |



#### 4. 数字 (Number)

- 可以是整数或浮点数。
- 可以有符号（正负号）。
- 可以使用指数形式（`e` 或 `E`）。
- **示例**： `123`, `-50`, `12.34`, `0.8e3` (即 800)



###  JSON 示例

```json
{
  "company": "Tech Corp",
  "founded": 2005,
  "isPublic": true,
  "ceo": null,
  "offices": [
    {
      "city": "San Francisco",

    },
    {

    }

  "products": [
    "Widget Pro",
    "Gadget Max"
  ],
  "financials": {
    "revenue": 10000000,
    "employees": 250
  }
}
```



### 注意事项

1. **JSON 是纯文本**： 它不包含函数、日期或二进制数据（但日期可以用特定格式的字符串表示，如 `"2023-10-27"`）。

2. **严格的引号**： **所有的键和所有的字符串都必须使用双引号 `""`**。这是新手最容易犯错的地方。

3. **尾随逗号禁止**： 对象或数组的最后一个元素后面**不能有逗号**。以下格式是**错误的**：

   ```json
   // 错误示例！
   {
     "name": "Alice", // 这个逗号是允许的
     "age": 30,       // 这个尾随逗号是禁止的！
   }
   ```

4. **注释**： **标准 JSON 格式不支持注释**（如 `//` 或 `/* */`）。虽然一些解析库可能支持，但为了最大兼容性，应避免使用。

5. **文件扩展名**： JSON 文件通常使用 `.json` 作为扩展名。

6. **MIME 类型**： 在网络上传输时，其标准的 MIME 类型是 `application/json`。
