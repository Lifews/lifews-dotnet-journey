# 反射&特性

特性必定用到反射，反射不一定用到特性

| 概念     | 解释                                   | 关键点                                          |
| :------- | :------------------------------------- | :---------------------------------------------- |
| **反射** | 一个强大的运行时类型检查和行为机制。   | **“不一定特性”** - 它的能力远不止处理特性。     |
| **特性** | 一种为代码元素添加元数据的声明性标签。 | **“必反射”** - 它本身是静态的，需要反射来激活。 |



##  反射Reflection

- **是什么？**
  - 反射是 .NET Framework 提供的一种**运行时**机制。
  - 它允许程序在**运行时**动态地获取、检查和操作**类型信息**（类、结构、接口、枚举、委托）以及这些类型成员的元数据（方法、属性、字段、事件、构造函数）。
  - 简单来说，反射让程序能够“看到”自身的结构，或者加载并探索未知程序集（.dll 或 .exe）的结构，而不需要在编译时就知道这些类型的具体细节。

- **核心功能：**
  - **获取类型信息：** `Type.GetType("Namespace.ClassName")`, `object.GetType()`, `typeof(ClassName)`
  - **检查类型成员：** 获取方法 (`GetMethod()`, `GetMethods()`)、属性 (`GetProperty()`, `GetProperties()`)、字段 (`GetField()`, `GetFields()`)、事件、构造函数等。
  - **动态创建对象：** `Activator.CreateInstance(type)`
  - **动态调用方法/访问属性/字段：** `MethodInfo.Invoke()`, `PropertyInfo.GetValue()/SetValue()`, `FieldInfo.GetValue()/SetValue()`
  - **加载程序集：** `Assembly.Load()`, `Assembly.LoadFrom()`
  - **探索程序集内容：** 获取程序集中定义的所有类型、模块等。
- **主要用途：**
  - **插件系统：** 动态加载未知的DLL，发现其中实现特定接口的类并创建实例。
  - **序列化/反序列化：** 将对象状态转换为存储或传输格式（如XML, JSON）以及反向操作时，需要遍历对象的属性和字段。
  - **依赖注入容器：** 自动发现注册的服务和它们的依赖关系。
  - **ORM框架：** 将数据库记录映射到对象时，需要了解对象的属性及其与数据库列的对应关系。
  - **单元测试框架：** 发现测试类和方法并执行它们。
  - **代码分析工具：** 检查程序集的结构和元数据。
  - **延迟绑定：** 在编译时不知道具体类型，只能在运行时确定并操作。
- **缺点：**
  - **性能开销：** 反射操作比直接代码调用慢得多，因为它涉及大量的元数据查找和动态调用。
  - **安全性：** 反射可以绕过访问修饰符（如访问私有成员），需要谨慎使用。
  - **代码可读性和维护性：** 反射代码通常比较晦涩难懂。
  - **编译时错误检查缺失：** 许多错误（如方法名拼写错误）只能在运行时被发现。



## 特性Attribute

- **是什么？**
  - 特性是一种为代码元素（程序集、模块、类、结构、接口、枚举、构造函数、方法、属性、字段、事件、参数、返回值等）添加**声明性信息（元数据）** 的机制。
  - 它本身是一个**类**，继承自 `System.Attribute` 基类。
  - 特性不会直接影响它所附加的代码元素的执行逻辑。它的主要作用是**提供额外的描述信息**。
- **核心功能：**
  - **添加元数据：** 将自定义的或框架定义的描述信息附加到代码元素上。
  - **声明性编程：** 通过在代码上“贴标签”来指示编译器、框架或其他工具应该如何对待这些代码，而不是通过命令式代码来实现。
- **语法：**
  - 使用方括号 `[]` 将特性放置在它要修饰的代码元素的上方（或紧邻前方）。
  - 可以包含位置参数和命名参数。
- **主要用途：**
  - **标记序列化：** `[Serializable]` (告诉序列化器这个类可以序列化)
  - **标记过时成员：** `[Obsolete]` (告诉编译器和使用者该成员已过时)
  - **配置Web API/ MVC：** `[HttpGet]`, `[Route]`, `[Authorize]` (告诉框架如何路由请求和授权)
  - **单元测试：** `[TestClass]`, `[TestMethod]` (告诉测试框架哪些是测试类和测试方法)
  - **数据验证：** `[Required]`, `[StringLength]`, `[Range]` (提供验证规则)
  - **ORM映射：** `[Table]`, `[Column]` (指定类和属性如何映射到数据库表和列)
  - **自定义行为注入：** 通过特性标记，配合框架或反射，在运行时根据特性信息改变对象行为（如AOP）。
  - **添加文档信息：** `[Description]` (提供UI控件等的描述信息)
